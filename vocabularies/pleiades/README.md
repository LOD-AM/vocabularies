# Pleiades in LOD-AM

## Purpose in LOD-AM
Pleiades provides controlled vocabulary for archaeological sites with the ability to add custom entries for underrepresented regions - critical for research outside the Mediterranean and Orient.

## Key Terms We Use
- Place types: settlements, sanctuaries, temples, theaters, baths, roads, aqueducts, tombs
- Geographic identifiers for archaeological sites
- Cultural associations

## Deviations from Standard
None - we use Pleiades as-is.

## Example Snippet
```turtle
:my_site a crm:E53_Place ;
    crm:P67_refers_to <https://pleiades.stoa.org/places/12345> .
```
